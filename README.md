# BookNook 📚

**Live Site:** https://booknook-frontend-puce.vercel.app/

BookNook is an online library management application where users can explore books and manage their own book collections.

### Features
- 📖 Browse all available books.
- 🔍 View detailed information about each book.
- ➕ Add new books with relevant information.
- ✏️ Edit book details.
- 🗑️ Delete books from your collection.
- 👤 User authentication and personal book management.
- 🗄️ Store and manage book data using MongoDB.
